Before we start

Check your machine

Run this. Every line should print a version.

python3 --version    # 3.11 or newer
git --version
ssh -T git@github.com

If the last line does not greet you by name, that is the first thing we fix – the Linux track covers it, and a trainer can help you now.

How to hand in

  1. Clone the course repository.
  2. git switch -c firstname-lastname – your personal branch.
  3. Solve exercises in exercises/, committing as you go. Small commits, real messages.
  4. Push: git push -u origin firstname-lastname.
  5. Open a pull request against main and leave it open. You will get review comments.
